# ADR-001 狀態不放在模型裡

**背景**：雲端模型會被下架、會用完額度、會改計費。原系統兩年內換過 3 代模型；只要記憶或身分存在模型的對話視窗裡，換一次模型就失去一次。

**決定**：記憶、身分、狀態存在本地（SQLite＋向量索引），每一輪由程式組進上下文。模型只負責把這一輪的材料變成一句話，可以替換。

**代價**：每一輪要先做檢索和組裝，比直接聊天慢（原系統一輪中位數約 19 秒，生成只佔 15%）。檢索做得不好，模型就看不到該看的東西——這變成檢索的問題，而不是模型的問題。

**反例**：`tests/test_demo.py::test_swap_mouth_keeps_memory` 換掉生成層，撈到的記憶不變。如果記憶放在模型的對話歷史裡，換模型就等於清空。
