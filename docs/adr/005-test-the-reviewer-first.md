# ADR-005 用審查員之前，先用埋好的錯考它

**背景**：程式由 AI 撰寫，讀碼找問題也交給模型。模型審查員會過度宣稱（信心滿分但看錯）、會因為只看到一段程式而誤報、也會對什麼都說「看起來沒問題」。它說的話能不能用，不能憑感覺。

**決定**：給審查員看程式之前，先在程式裡故意埋錯，量兩個數字：埋的錯它抓到幾個（召回），乾淨的程式它標了幾行（誤報）。兩個都過線才用它的話；用的時候，它說的每一條再回程式碼逐條核對，分成證實、部分證實、它看錯。最後的驗證權留在人這邊。

**代價**：每換一個審查員（換模型、換提示詞）都要重考；埋錯的種類有限，考得過不代表什麼都抓得到；門檻要照自己的情況調。

**反例**：`tests/test_verification.py::test_counterexample_recall_alone_trusts_the_reviewer_that_flags_everything`——只量召回，「每一行都有錯」的審查員拿滿分；加上誤報那一個數字，它才現形。
