# 檢索與可靠性：原系統現況 vs 這裡示範的寫法

這一批裡有些做法**比原系統好**。每一列都寫清楚，不讓人以為原系統已經這樣做。

| 模組 | 原系統現況 | 這裡示範的 | 測試裡的反例 |
|---|---|---|---|
| `retrieval/keywords.py` 斷詞切關鍵字 | jieba 斷詞，繁體中文直接丟簡體詞庫 | 有 OpenCC 時先繁轉簡再斷，結果還原回繁體；沒裝 jieba 時退回字元雙字 | — |
| `retrieval/index.py` 關鍵字檢索 | 每個關鍵字用 `instr()` 掃整張表，只看「罕不罕見」 | SQLite FTS5 倒排索引＋BM25 排序 | 照命中次數排，閒聊天氣會贏過真正的關鍵字 |
| `retrieval/hybrid.py` 混合排序 | 語意×時間＋情緒加分，權重手調；相似度門檻分不出對錯 | 語意＋BM25 混合、時間衰減、MMR 去重；權重是參數，該用標好答案的題庫調 | 沒有 MMR 時，前兩名是同一件事換句話說 |
| `retrieval/router.py` 要不要查 | 模型判斷；模型失敗或格式不對時全部回「不查」 | 模型判斷，失敗時退回規則 | 「失敗＝不查」會漏掉明明在問往事的句子 |
| `reliability/failover.py` 模型遞補 | 備援設定跟主力是同一顆，本機最後備援沒開 | 主力 → 不同家的備援 → 本機；設定有「備援＝主力」「全部同一家」時直接報出來 | 備援＝主力時，一次故障全部不回 |
| `reliability/fail_loud.py` 解析模型輸出 | 解析失敗時填中性預設值往下送 | 失敗就是失敗，不填假值 | 填預設值後，壞掉的回答跟真的「中性」一模一樣 |
| `reliability/alarms.py` 告警 | 同（原系統已經這樣做） | 同一個告警只留一列、計次、標慢性；機器故障預設不送進 agent | — |

全部測試：`python -m unittest discover -s tests -v`（不需要 GPU、不需要模型；jieba／OpenCC 沒裝也能跑）。
